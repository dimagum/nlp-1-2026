## Как вопросы связаны между собой

```
one-hot → счётные (BoW, TF-IDF, PPMI+SVD) ──┐
                                            ├─→ эмбеддинги слов (word2vec, GloVe, fastText)
                     предсказательные ──────┘            │
                                                         ▼
       RNN/LSTM → seq2seq (encoder-decoder) → + attention → Transformer
                                                               │
                         ┌─────────────────────────────────────┼──────────────────┐
                    encoder-only (BERT)             decoder-only (GPT)     enc-dec (T5)
                                                               │
                        промптинг (ICL, CoT) · PEFT (LoRA) · RLHF/DPO · RAG
```

## Шпаргалка ключевых формул

| Что | Формула |
|---|---|
| TF-IDF | $\text{tf}(t,d)\cdot\log\frac{N}{\text{df}(t)}$ |
| Skip-gram | $P(o\mid c)=\frac{\exp(u_o^\top v_c)}{\sum_w \exp(u_w^\top v_c)}$ |
| Negative sampling | $\log\sigma(u_o^\top v_c)+\sum_k\log\sigma(-u_{w_k}^\top v_c)$ |
| LSTM-память | $c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$ |
| Attention | $\text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$ |
| Температура | $p_i=\frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$ |
| Perplexity | $\exp\left(-\frac1N\sum_i\log P(w_i\mid w_{<i})\right)$ |
| BLEU | $\text{BP}\cdot\exp\left(\sum_{n=1}^4 \tfrac14\log p_n\right)$ |
| LoRA | $W=W_0+\frac{\alpha}{r}BA$ |
| Reward model | $-\log\sigma\big(r(x,y_w)-r(x,y_l)\big)$ |
| DPO | $-\log\sigma\left(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}\right)$ |
| RRF | $\sum_r \frac{1}{k+\text{rank}_r(d)}$ |
